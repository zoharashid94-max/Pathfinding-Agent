# Pathfinding Agent Using A* and Dijkstra's Algorithms

## Project Overview

This project explores how pathfinding algorithms can find routes through a grid. It was developed as part of my AI internship to gain practical experience with search algorithms and understand how different approaches explore possible paths.

The project implements **A*** and **Dijkstra's algorithm** on a 10 × 10 grid. It uses Manhattan distance as the heuristic for A* and compares the algorithms based on their pathfinding results and the number of nodes explored.

## Objectives

- Understand how search algorithms find paths through a grid.
- Implement A* and Dijkstra's algorithms.
- Use Manhattan distance as a heuristic for A*.
- Compare the algorithms' pathfinding behaviour.
- Visualize and examine the resulting paths.

## Technologies Used

- Python
- Jupyter Notebook
- A* Search Algorithm
- Dijkstra's Algorithm
- Manhattan Distance

## Methodology

1. Create a 10 × 10 grid for the pathfinding environment.
2. Define the starting point, destination, and allowed movement directions.
3. Implement Dijkstra's algorithm to find a path based on accumulated movement cost.
4. Implement A* using Manhattan distance to guide its search toward the destination.
5. Run both algorithms on the grid.
6. Examine the resulting paths and the number of nodes explored.

## Results

The notebook records the pathfinding results for both algorithms. In the recorded A* run, the algorithm found a path of 18 steps and explored 80 nodes.
